# AD Interior Studio website

Static site: no build step. Open `index.html`, or serve the folder:

```
python3 -m http.server 4173
```

Pages: `index.html` (scroll house tour), `about.html`, `careers.html`, `contact.html`.
Styles in `css/style.css`, behaviour in `js/main.js`, images and hero video frames in `assets/`.
